# Тестирование ПО — команда 4

ПР7. Вариант 4 «Оформление заказа»

Шесть UI-автотестов Playwright для локального OWASP Juice Shop. Проверено на Juice Shop v20.4.0-SNAPSHOT, Playwright 1.65.1 и Chromium.

| Группа | Сценарии |
| --- | --- |
| Корзина и адрес | ORD-01 Пустая корзина. ORD-02 Выбор адреса и обязательный город. |
| Доставка и оплата | ORD-03 Выбор доставки и бесплатный стандартный тариф. ORD-04 Недоступная оплата пустым кошельком и выбор учебной карты. |
| Подтверждение заказа | ORD-05 Сводка и итог 2.98¤ с доставкой 0.99¤. ORD-06 Подтверждение, очистка корзины и отслеживание товара. |

## Запуск

В первом терминале запустите OWASP Juice Shop. Адрес для тестов — `http://127.0.0.1:3000`.

```sh
docker run --rm -p 127.0.0.1:3000:3000 bkimminich/juice-shop
```

Во втором терминале из папки репозитория:

```sh
npm ci
npx playwright install chromium
npm test
npm run report
```

Каждый тест создаёт своего пользователя с вымышленными данными в локальном контейнере. Сценарий ORD-06 завершает заказ в симуляторе с учебной картой. Для отчёта Playwright сохраняет скриншоты, при падении — также трассу.
